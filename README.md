# tip-calculator

A simple tip calculator in Python.

## What the program does

This program asks for the bill amount, the tip percentage, and the number of people. Then it calculates the tip, the total value, and how much each person pays.

## How to use

You need an app to run Python, such as Pydroid 3.

1. Copy the code from `tip_calculator.py`.
2. Paste it into the app.
3. Run it.

On a computer, run this command in the terminal:

```
python tip_calculator.py
```

## Example

```
What is the bill amount? 100
What is the tip percentage? 10
Between how many people will it be divided? 2
The tip is R$ 10.0
The total value is R$ 110.0
Everyone will pay R$ 55.0
```
